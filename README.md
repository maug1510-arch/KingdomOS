# Kingdom OS

Kingdom OS is an advanced Google Sheets management system for Rise of Kingdoms kingdoms.

## Features

- 📊 Modern Dashboard
- 👥 Players Database
- 🏆 Automatic Rankings
- 📈 Kingdom Statistics
- 📅 Monthly Snapshots
- 🤖 Google Apps Script Automation
- 📤 Alliance Export
- 🔍 Governor Search
- ⚠ Data Validation & Warnings
